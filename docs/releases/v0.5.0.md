# Wefax 0.5.0

## HackRF One como receptor

Además de SDRplay, RTL-SDR y KiwiSDR, Wefax puede recibir con un **HackRF One**.

- En **Receptor > Equipo** elija *HackRF One*. Recibe desde 1 MHz: las cartas de onda corta sin conversor; las de onda larga (Pevek, 148 kHz) no.
- No tiene ganancia automática: la de FI (0 a 40 dB) y la de banda base (0 a 62 dB) se ponen a mano; empiece con 16 y 20. El amplificador de RF, mejor apagado en onda corta.
- Sus muestras son de 8 bits: con emisoras fuertes cerca, un filtro de paso de banda de HF ayuda.
- Solo recibe: Wefax no tiene nada que ponga el HackRF a emitir.
- Es opcional: sin `libhackrf-dev`, Wefax compila igual, sin él.

## Actualizar

Si va a usar un HackRF, instale antes su librería:

```bash
sudo apt install libhackrf-dev hackrf
```

```bash
git pull
autoreconf -i && automake --add-missing; autoreconf
./configure && make clean && make
sudo make install
sudo systemctl restart wefax-web wefax-receiver
```

`./configure` debe acabar con `HackRF yes`. El usuario de los servicios debe estar en el grupo `plugdev` para abrir el USB. Después, Ctrl+F5 en la página.
