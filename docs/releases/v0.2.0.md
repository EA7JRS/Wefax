# Wefax 0.2.0

Receptor de radiofacsímil meteorológico (WEFAX) de onda corta para SDRplay y RTL-SDR. Primera versión que se puede instalar entera: receptor, interfaz web y servicios.

> **Sin probar con una señal real del aire.** Todo lo comprobado se hizo en el PC con señales generadas por las propias pruebas. La parte de SDRplay no se ha compilado nunca: se compila por primera vez donde esté su API.

## Qué trae

- **Descodificador**: índice 576 y 288; 60, 90, 120 y 240 líneas por minuto; tonos de inicio y parada, enfasado; corrige el error de frecuencia y de reloj del receptor.
- **Receptor** (`wefaxreceiver`): SDRplay, RTL-SDR o grabación; frecuencia fija o servicio que sigue el horario; cartas en PNG; puede turnarse el equipo con [Navtex](https://github.com/EA7JRS/Navtex).
- **Interfaz web** (`wefaxwebserver`, puerto 8081): cartas con visor, carta en curso, horario de 24 horas, estaciones y ajustes. Claro, oscuro y noche; español e inglés. Sin contraseña: solo en una red de confianza.
- **Estaciones**: Boston, Nueva Orleans, Point Reyes, Kodiak y Honolulu, de los horarios por estación del National Weather Service (diciembre de 2024); Hamburgo / Pinneberg, Northwood, Atenas y Múrmansk (estas dos, dudosas), del horario mundial de la NOAA (marzo de 2025). Transcritas con un lector automático: sin cotejar línea a línea con el original.
- **Ayuda** «Cómo leer una carta», con la escala Beaufort.
- **Posición del GPS**: la toma de gpsd, como Navtex, y la muestra.
- **Servicios** de systemd y `tools/instalar-servicios.sh`.

## Instalar

```bash
sudo apt install git build-essential autoconf automake zlib1g-dev libcjson-dev libsqlite3-dev libmicrohttpd-dev librtlsdr-dev
git clone https://github.com/EA7JRS/Wefax.git && cd Wefax
autoreconf -i && automake --add-missing; autoreconf
./configure && make && make check
sudo make install
sudo sh tools/instalar-servicios.sh
sudo ufw allow from 192.168.0.0/16 to any port 8081 proto tcp   # si hay cortafuegos; ponga el rango de su red
```

Descargue el código en su carpeta personal, no en `/opt/Wefax`. Como `root` sin `sudo`, el instalador pide `--usuario <nombre>`. Después, `http://<equipo>:8081/`: elija estaciones y encienda el receptor. El [README](../../README.md) trae la instalación paso a paso, todos los comandos y la solución de problemas.

## Probado en un equipo real

- Compila en Debian 13 con la API de SDRplay y librtlsdr, pasa `make check`, se instala y los servicios arrancan; la interfaz se abre desde la red local.

## Sin probar

- Ninguna señal real, con ningún receptor.
- El turno con Navtex contra un Navtex en marcha.

## Sin hacer

- Más estaciones (Asia, Chile, Canadá, Australia).
- Enfasado simétrico y onda larga.
- No recibe imágenes de satélite.
