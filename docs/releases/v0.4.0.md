# Wefax 0.4.0

## KiwiSDR como receptor

Además de SDRplay y RTL-SDR, Wefax puede recibir con un **KiwiSDR de la red**, el suyo o uno ajeno.

- En **Receptor > Equipo** elija *KiwiSDR* y escriba su nombre o dirección, el puerto (8073) y la contraseña si la pide.
- Siguiendo el horario, Wefax solo se conecta un minuto antes de cada emisión y lo deja al acabar.
- La página enseña la posición que declara el KiwiSDR y un botón para usarla: la propagación y la frecuencia automática deben calcularse desde donde está el receptor.
- Los KiwiSDR públicos limitan el tiempo de cada visitante y tienen dueño: para un uso continuo, uno propio o con permiso.

## Actualizar

```bash
git pull
autoreconf -i && automake --add-missing; autoreconf
./configure && make
sudo make install
sudo systemctl restart wefax-web wefax-receiver
```

Los servicios no cambian. Después, Ctrl+F5 en la página.

## Probado y sin probar

- **Probado:** `make check`, 183 comprobaciones; el programa entero contra un KiwiSDR de pega hecho para la prueba.
- **Sin probar:** un KiwiSDR de verdad, y, como hasta ahora, una señal real del aire con cualquier equipo.
